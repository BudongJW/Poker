# pokerlab

자체 텍사스 홀덤 시뮬레이터와 승률(에퀴티) 계산기입니다. 같은 저장소의 `poker/`(실제 포커 사이트 화면을 읽는 봇)와는 완전히 독립적이며, 화면 인식·마우스 제어·외부 서버가 필요 없습니다. 의존성은 NumPy와 pandas(리포트용)뿐입니다.

| 모듈 | 역할 |
|---|---|
| `cards.py` | 카드 표기(`As`, `Td`) 파싱, 169개 스타팅 핸드 분류 |
| `evaluator.py` | 5~7장 족보 평가기 (단건용 순수 Python + 대량용 NumPy 벡터화) |
| `equity.py` | 승률 계산: 경우의 수가 적으면 전수 계산, 아니면 몬테카를로. 상대 레인지 지정 가능 |
| `preflop.py` | 프리플랍 승률 테이블(169핸드 × 상대 1~8명), 레인지 표기(`TT+, AQs+, 15%`) 파서 |
| `advisor.py` | 내 핸드·보드·인원·팟 오즈를 받아 한국어 해석 출력 |
| `engine.py` | 노리밋 홀덤 한 판 진행 (블라인드, 최소 레이즈, 올인, 사이드팟, 스플릿) |
| `bots.py` | 봇 7종: `station`, `random`, `maniac`, 에퀴티 기반 `nit`/`tag`/`lag`/`tag_range` |
| `selfplay.py` | 봇끼리 자동 대전시키고 모든 핸드를 SQLite에 누적 (멀티프로세스, 중단 후 이어하기) |
| `report.py` | 누적 DB에서 봇별 bb/100, 포지션·인원·핸드별 통계, 에퀴티 보정 분석 |

## 사용법

저장소 루트에서 실행합니다.

```bash
python -m pokerlab equity AsKs --board "Qs Js 2d" --players 4 --pot 100 --to-call 50
```

```
[플랍] 내 핸드 As Ks (AKs) | 보드 Qs Js 2d | 4명 (상대 3명, 랜덤 핸드 가정)
승률(에퀴티) 57.7%  = 승 57.0% + 무 1.5% 분배 / 패 41.5%   (몬테카를로 200,000회, 오차 ±0.21%)
판정: 강함  (인원 기준 평균 승률 25.0%의 2.31배)
현재 족보: 하이카드  | 지금 당장 쇼다운이면 랜덤 핸드 1개 상대로 앞섬 59.2% / 동률 0.8% / 뒤짐 40.0%
리버까지 갔을 때 내 최종 족보: 플러시 30.6%, 원페어 29.2%, 하이카드 17.4%, 스트레이트 10.0%, ...
상대 수별 승률: 1명 76%  2명 64%  3명 58%  4명 54%  5명 51%  6명 49%  7명 47%  8명 45%
팟 오즈: 팟 100에 50 콜 -> 필요 승률 33.3%, 내 승률 57.7% -> 콜 기대값 +36.6 (수익 콜)
```

상대 레인지를 알면 `--range`로 지정합니다(상대 한 명당 한 번).

```bash
python -m pokerlab equity AhKd --players 2 --range "QQ+,AKs"
```

봇 자가대전으로 데이터를 모으고 통계를 봅니다. `--hands`와 `--seconds`를 모두 생략하면 Ctrl-C까지 계속 수집하고, 같은 DB로 다시 실행하면 이어서 쌓입니다.

```bash
python -m pokerlab simulate --db selfplay.sqlite --hands 200000 --players 2,6,9 --bots tag,lag,nit
```

```bash
python -m pokerlab report --db selfplay.sqlite
```

Python에서 직접 쓸 수도 있습니다.

```python
from pokerlab.equity import equity
from pokerlab.preflop import parse_range

r = equity("AsKs", "Qs Js 2d", n_opponents=3)                    # r.equity, r.win, r.tie, r.hand_dist
r = equity("AhKd", n_opponents=1, ranges=[parse_range("QQ+")])   # 상대 레인지 지정
```

테스트는 `python -m pytest pokerlab`입니다.

## 검증 결과

- **족보 평가기**: 5장 조합 2,598,960개와 7장 조합 133,784,560개를 전수 평가한 족보별 빈도가 알려진 값과 정확히 일치합니다. 서로 다른 등급 수도 7,462개로 맞습니다. 속도는 벡터화 기준 초당 약 1,300만 핸드, 단건 호출은 핸드당 약 1.2μs입니다.
- **승률 계산기**: 상대 1명 프리플랍 승률이 전수 계산 기준값과 0.05%p 이내입니다(AA 85.22/85.20, KK 82.39/82.40, AKs 67.00/67.04, 72o 34.60/34.58). 상대 2·5·8명도 독립 시뮬레이션 값과 0.1%p 이내입니다. 포스트플랍 전수 계산과 몬테카를로는 표준오차 0.5배 이내로 일치합니다.
- **계산 시간**: 6인 프리플랍 10만 회 약 0.10초, 9인 약 0.14초. 플랍 1:1 전수 계산(1,070,190가지) 약 0.17초.
- **엔진과 데이터 파이프라인**: 콜링 스테이션만 앉혀 모든 핸드를 쇼다운까지 보낸 160만 핸드에서, 스타팅 핸드 169종 × 인원 2~9명 = 1,352개 칸의 실측 팟 점유율이 이론 승률과 통계적으로 일치했습니다(2σ 이내 94.9%, 3σ 이내 99.7%. 정규분포 기대치는 95.4%, 99.7%).

## 자가대전 실험 (4 vCPU 컨테이너)

**수집 속도**

| 봇 구성 (6인, 액션 로그 포함) | 1코어 | 4코어 |
|---|---|---|
| 에퀴티 기반 봇 (`tag`, `lag`, `nit`) | 1,230 핸드/초 | 4,544 핸드/초 |
| 계산 없는 봇 (`station`, `random`, `maniac`) | 6,414 핸드/초 | 14,469 핸드/초 |

저장 용량은 액션 로그 포함 시 핸드당 약 0.8~1.0KB, 제외 시 약 0.3KB입니다.

**혼합 리그** (6인, 40만 핸드, 손익 합계 0)

| 봇 | VPIP | PFR | bb/100 (95% 신뢰구간) |
|---|---|---|---|
| lag | 29.6% | 15.4% | +1,146 ± 23 |
| tag | 12.5% | 3.3% | +601 ± 15 |
| nit | 5.4% | 0.8% | +330 ± 11 |
| maniac | 91.4% | 60.7% | −646 ± 31 |
| station | 96.0% | 0% | −699 ± 32 |
| random | 81.7% | 30.6% | −731 ± 28 |

**에퀴티 봇끼리만** (6인, 30만 핸드): nit +53 ± 5, tag +29 ± 7, lag −82 ± 9 bb/100. 약한 상대가 없어지면 수익 폭이 10분의 1 이하로 줄고, 혼합 리그 1위였던 lag가 최하위가 됩니다.

**상대 레인지 가정의 효과**: 레이즈한 상대를 상위 20% 핸드로 가정하는 `tag_range`는 `tag`와의 1:1(30만 핸드)에서 +154 ± 9 bb/100으로 이겼습니다. 반면 아무 카드로나 레이즈하는 `maniac`이 있는 6인 리그에서는 `tag`(+641)보다 낮은 +463이었습니다. 레인지 가정은 상대 유형에 맞을 때만 이득입니다.

**랜덤 핸드 가정 승률의 한계**: 리버에서 봇이 계산한 "랜덤 핸드 상대 승률"과 실제 쇼다운 팟 점유율을 비교했습니다.

| 계산된 승률 | 실제 (혼합 리그) | 실제 (에퀴티 봇끼리) |
|---|---|---|
| 45% | 46% | 33% |
| 55% | 55% | 39% |
| 65% | 66% | 46% |
| 75% | 74% | 60% |
| 85% | 85% | 79% |
| 95% | 95% | 92% |

상대가 아무 핸드로나 쇼다운에 오면 계산값이 그대로 맞지만, 상대가 핸드를 골라서 남으면 중간 강도 핸드의 승률이 크게 과대평가됩니다.

## 한계

- 봇은 단순한 규칙 기반이며 균형 전략(GTO)이 아닙니다. 위 수치는 이 봇 풀 안에서의 결과이고, 사람이 치는 게임의 수익률을 뜻하지 않습니다.
- 매 핸드 스택을 100bb로 초기화하고 좌석을 섞습니다. 레이크·앤티·토너먼트 구조는 없습니다.
- 승률은 "지금 올인해서 끝까지 갔을 때"의 값입니다. 이후 베팅 라운드와 포지션의 영향은 반영하지 않습니다.
- 전수 계산은 포스트플랍 상대 1명, 턴·리버 상대 2명까지만 지원하고 나머지는 몬테카를로입니다.
- 프리플랍 테이블(`data/preflop_equity.json`)은 칸당 100만 회 몬테카를로 값이라 ±0.1%p 수준의 오차가 있습니다. `python -m pokerlab preflop-table`로 다시 만들 수 있습니다(4코어 약 4분).
