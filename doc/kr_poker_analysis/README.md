# 국내 포커 게임 분석 — UI·디자인 구조와 게임별 특징

WPL, 피망, 한게임 등 국내 주요 포커 게임을 공개 자료로 분석해 정리한 문서 묶음이다. 1부는 화면 구성과 디자인 구조를, 2부는 게임 자체의 특징(종목·규칙, 베팅·정산, 재화·과금, 대회, 운영 정책)을 다룬다.

- 분석 기준일: 2026-11-13
- 대상: 넷마블(잼팟)·네오위즈·NHN 3사의 포커 앱 8종
- 자료: 앱스토어·구글 플레이 스크린샷과 설명·업데이트 노트, 공식 가이드·공지·약관, 보도자료·기사, 이용자 플레이 후기 캡처
- 실제 클라이언트에 로그인해 확인한 내용은 없다. 접근을 막아 둔 사이트는 우회하지 않고 조사에서 뺐다.
- 저작권이 있는 스크린샷은 저장소에 넣지 않았다. 화면 구조는 ASCII 와이어프레임으로 다시 그렸고, 원본은 각 문서의 「근거 자료」 표에 있는 URL에서 확인할 수 있다.

## 읽는 법

### 근거 등급
모든 서술에는 아래 셋 중 하나가 붙는다.

| 표기 | 뜻 |
|---|---|
| **[관찰]** | 스크린샷이나 공식 자료에서 직접 확인한 사실 |
| **[추정]** | 관찰한 내용에서 끌어낸 해석. 틀릴 수 있다 |
| **[미확인]** | 자료를 구하지 못해 알 수 없는 부분 |

### 근거 ID
| 형식 | 뜻 |
|---|---|
| `AS-<앱키>-<iphone\|ipad>-NN` | 앱스토어 스크린샷 N번째 (예: `AS-wpl-iphone-02`) |
| `GP-<앱키>-NN` | 구글 플레이 스크린샷 N번째 (02 문서에서 사용. 01·03 문서는 구글 플레이 자료도 `WEB-N`으로 적었다) |
| `STORE-<앱키>` | 앱스토어 설명·업데이트 노트·버전 기록 (2부 문서에서 사용) |
| `WEB-N` | 그 밖의 웹 자료. 번호는 **문서마다 따로** 매긴다 |

앱키: `wpl`, `winjoy`, `pmang_poker`, `pmang_showdown`, `hangame_poker`, `hangame_classic`, `hangame_royal`, `hangame_holdem`.

### 와이어프레임과 좌표
- 와이어프레임은 정렬이 깨지지 않도록 박스 안 라벨을 ASCII로 적고, 아래 범례에서 한국어로 풀어 썼다.
- 위치는 화면 왼쪽 위를 (0%, 0%), 오른쪽 아래를 (100%, 100%)로 본 비율이다. 스크린샷에서 눈으로 읽은 근사값이다.
- 색상 HEX는 스크린샷의 해당 영역을 샘플링한 대표색이다. JPEG 압축과 조명 효과 때문에 실제 에셋 값과 조금 다를 수 있다.

## 한계

- 2부의 수치(한도 환산, 딜러비, 시드, 레이크 캡, 대회 상금)는 2026년에만 여러 번 바뀌었다. 각 문서에 적힌 날짜 기준이며, 인용하기 전에 원 공지를 다시 확인해야 한다.
- pmang.com(피망 약관·운영정책·공식 가이드)과 윈조이 고객센터(운영정책)는 자동 또는 해외 접속을 막아 열지 않았다. 그 안에만 있는 내용은 [미확인]으로 남겼다.
- 실제 클라이언트에 로그인해 캡처한 화면이 아니다. 홍보용 스크린샷은 연출이 들어가 있고 카피가 화면 일부를 가리므로, 가려진 부분은 다른 자료로 보완하거나 [미확인]으로 남겼다.
- 앱은 자주 개편된다. 버전·날짜는 위 표의 분석 시점 기준이며, 일부 자료(예: 피망 포커 로비)는 구버전 캡처다. 문서에 연도를 밝혀 두었다.
- 모바일 화면이 중심이다. PC 클라이언트는 공개 자료가 있는 범위에서만 다뤘다: 한게임포커 PC(공식 가이드 이미지, → 03 §3.B·§4.D·§4.E), 한게임 로얄홀덤 PC(영상 프레임, → 03 §4.A), WPL PC(스토어 컷, → 01 §4.1), 윈조이 포커 PC(2010~2011년 제작으로 보이는 구형 가이드, → 01 §W.4). 피망 포커 PC와 피망 쇼다운 홀덤 PC는 캡처를 구하지 못했다.

## 자료를 다시 모으려면

스크린샷은 저장소에 없으므로, 갱신할 때는 아래 공개 경로에서 다시 받는다.

- 앱스토어: `https://itunes.apple.com/lookup?id=<App Store ID>&country=kr` 응답의 `screenshotUrls`, `ipadScreenshotUrls`. URL 끝의 크기 지정(`392x696bb.jpg` 등)을 `2400x2400bb.jpg`로 바꾸면 원본에 가까운 해상도를 받는다.
- 구글 플레이: `https://play.google.com/store/apps/details?id=<번들 ID>&hl=ko&gl=KR` 페이지의 스크린샷 이미지.
- 기사·후기: 각 문서 「근거 자료」 표의 URL.
