# 국내 포커 게임 특징 비교 — 8개 게임을 가로로 보기

> 분석 기준일: 2026-11-13. 이 문서는 회사별 특징 문서 세 편을 가로로 묶은 요약이다.
> 개별 사실의 근거(공지·기사 URL)와 [관찰]/[추정] 구분은 각 문서에 있다. 여기서는 `→ 05 WPL §4`처럼 해당 절만 가리킨다.
> (05 = 넷마블 WPL·윈조이, 06 = 네오위즈 피망, 07 = NHN 한게임. 화면 구성은 01~04 문서)
> 금액은 따로 밝히지 않으면 게임 재화이고, 실제 돈에는 "원"을 붙였다.

## 1. 핵심 결론

1. **세 회사가 같은 2층 구조를 쓴다.** 오래된 웹보드 종합 포커가 수익을 받치고, 뒤에 나온 홀덤 전용 게임이 대회와 새 이용자를 맡는다.

   | | 웹보드 종합 (먼저 나온 쪽) | 홀덤 전용 (나중에 나온 쪽) |
   |---|---|---|
   | 넷마블(잼팟) | 윈조이 포커 — 모바일 2015, '윈조이' 브랜드 2019 | WPL — 2020-12 |
   | 네오위즈 | 피망 포커 — 2013-08 | 피망 쇼다운 홀덤 — 2024-12 |
   | NHN | 한게임 포커 — 2014 / PC 한게임포커 — 1999, 클래식 2019 | 한게임 로얄홀덤 — 2023-01(더블에이 포커), 2025-09 리뉴얼 |

   NHN만 한 줄이 더 있다. 5인 캐주얼 홀덤을 단독 앱(한게임 홀덤, 2025-09)으로 떼어 냈다. (→ 07 §0.1)

2. **홀덤 전용 3종은 모두 "게임 안 예선 → 현금 상금 오프라인 본선"을 중심에 둔다.** WPL의 홀덤 마스터스(9회차 총상금 24억 원), 로얄홀덤의 HPT(6회 22억 원), 쇼다운 홀덤의 PFGT 챔피언스 리그(10억 GTD)다. 세 곳 모두 본선의 주최는 외부 단체이고 게임사는 후원사이며, 참가권은 본인만 쓸 수 있다. (→ §6)

3. **게임머니 숫자의 크기는 게임마다 수만 배 다르다.** 1만 원이 WPL에서는 약 1억 코인, 윈조이 포커에서는 3조 3,000억 조이코인이다. 화면의 금액을 게임 사이에 비교하려면 원화 환산이 필요하다. (→ §5)

4. **과금 방식이 닮았다.** 게임머니를 직접 팔지 않고 아바타·이모티콘·카드덱 같은 아이템에 얹어 준다. 그 위에 월정액과 누적 결제 VIP가 있고, 최근에는 스토어 밖 결제(웹 상점, PC 전용 상품)에 보너스를 붙인다. (→ §5)

5. **2026년에 같은 방향의 개편이 겹쳤다.** 패스트폴드(WPL 코인러시와 한게임 러시홀덤이 같은 달인 2026-04에 나왔다), 레이크 레이스, PC 버전 확장(쇼다운 홀덤 PC 2026-03, 로얄홀덤 PC 개별 창 2026-05), 한국식 홀덤의 정통 룰 수렴(한게임 5인 홀덤의 최소 레이즈·정통 베팅셋 2026-10)이다. (→ §9)
