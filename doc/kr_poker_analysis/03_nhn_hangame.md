## 7. UX 특징 · 차별점 · 약점

- **이중 베팅 문법**: 웹보드 라인은 "판돈 비율 버튼(삥·따당·쿼터·하프·풀/맥스)" 또는 "금액 라벨 버튼(2억·5억·10억)"으로 한 번 터치에 끝나고, 로얄홀덤은 슬라이더+BB 프리셋. 2026-10 리뉴얼로 PC·클래식·한게임 홀덤에 "정통 베팅셋"이 추가되어 한 앱 안에서 두 문법을 전환할 수 있게 됨 [관찰: WEB-12, WEB-6].

### 신뢰도·한계
- **직접 설치·로그인해서 본 화면은 없다.** 모든 관찰은 스토어 스크린샷, 공식 가이드 이미지, 기사 이미지, 유튜브 자동 생성 정지 프레임(영상당 3장, 1280×720)에 한정된다.
- 스토어 스크린샷은 원근 변형·합성·캡션이 들어간 마케팅 컷이라 좌표(%)는 ±3~5%p 오차의 근사다. 실측에 가까운 것은 공식 가이드 이미지(WEB-9, WEB-12)뿐이다.
- 영상 프레임은 스트리머 캠·오버레이가 창 일부를 가린다. 로얄홀덤 PC 좌석 좌표를 수치로 적지 않은 이유다.
- 가장 불확실한 서술: 로얄홀덤 **모바일** 액션 버튼 전체 구성(체크 외 미판독), 한게임 홀덤의 베팅 UI 전환 방식, 한게임 포커(모바일) 현행 로비, 각종 체크박스·알약 슬롯의 기능(예약으로 추정), 빨간 "V nn" 태그의 의미.
