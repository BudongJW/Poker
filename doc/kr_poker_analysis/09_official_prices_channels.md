# 게임머니 공식 가격과 판매 경로

> 분석 기준일: 2026-11-13 · 근거 등급: **[관찰]** = 공식 상점·스토어 페이지에서 직접 확인, **[추정]** = 확인한 수치에서 계산하거나 끌어낸 해석, **[미확인]** = 자료 없음
> 근거 ID는 문서 끝 「근거 자료」 표를 가리킨다. `STORE-<앱키>` = 앱스토어 페이지의 앱 내 구입 목록, `WEB-N` = 이 문서 안에서만 쓰는 번호. 다른 문서의 근거는 `→ 07 클래식 §5`처럼 절로 가리킨다.

**이 문서가 다루는 범위**: 게임사가 직접 운영하는 판매 경로(앱 마켓 인앱 결제, 공식 웹·PC 상점, 정기구독)와 거기에 표시된 가격이다.

**다루지 않는 것**: 게임머니를 현금으로 사고파는 비공식 거래(이른바 머니상)의 시세와 거래처. 게임산업법이 금지하는 환전·환전 알선에 해당하고 세 회사 모두 제재 대상으로 삼기 때문에 수집하지 않았다. 확인한 법적 지위와 제재 규정은 §5에 적었다.

## 1. 한눈에 보기 — 공식 경로에서 1만 원으로 받는 게임머니

- 표시 가격은 정가다. 실제로는 보너스 쿠폰, 회원제 추가 지급, 웹 상점 보너스가 붙어 받는 양이 달라진다(§3).
- 한 사람이 한 달에 결제할 수 있는 금액은 본인 명의 계정 합산 100만 원이다(2026-02-03~). (→ 08 §4.1)

## 4. 공식적으로 머니가 옮겨 가는 경로

| 경로 | 조건 | 근거 |
|---|---|---|

| 한게임 PC·클래식 보유머니 이동 | 동일 명의 계정 사이, 신 등급(1억 골드 이상), 수수료 5% | → 07 클래식 §5 |

- 모두 같은 사람의 계정·게임 사이에서만 움직인다. 유료로 얻은 게임머니를 다른 사람에게 보내는 공식 경로는 없다. 시행령이 게임머니 이체를 막고 있기 때문이다. (→ 06 피망 포커 §8)

## 5. 비공식 거래(환전)의 법적 지위

게임머니를 현금으로 사고파는 거래의 시세와 거래처는 이 문서 묶음에 기록하지 않는다. 확인한 사실은 다음과 같다.

| 구분 | 내용 | 근거 |
|---|---|---|
| 법률 | 게임산업진흥에 관한 법률 제32조 제1항 제7호: 게임물 이용으로 얻은 결과물(게임머니 등)을 환전·환전 알선하거나 재매입을 업으로 하는 행위 금지 | WEB-3 |
| 벌칙 | 같은 법 제44조 제1항 제2호: 5년 이하의 징역 또는 5천만 원 이하의 벌금. 위반에 쓰인 게임물·기기는 몰수 대상 | WEB-3 |
| 대상 게임머니 | 대상은 시행령 제18조의3이 정한다. 제3호 (라)목은 "게임물을 이용하여 업으로 게임머니 또는 게임아이템 등을 생산·획득하는 등 게임물의 비정상적인 이용을 통하여 생산·획득한 게임머니 또는 게임아이템 등의 데이터"를 든다. 포커류 게임머니의 환전이 이 법으로 금지된다는 점은 윈조이 공지가 직접 밝힌다 | WEB-4, → 05 WPL §5 |
| 사는 쪽 | 환전되는 게임머니를 걸고 게임을 하면 형법상 도박죄가 문제 될 수 있다는 변호사 해설이 있다 | WEB-3 |
| 한게임 | 이용제한규정: 게임머니 환전·환전 알선·재매입 → 1년 전체 게임 이용제한(동일정보 ID 전부). 머니 매매·유도 → 1년. 제한 사유로 얻은 게임자산은 회수 | → 07 §0.2 |
| 윈조이(WPL 포함) | 공지: 게임머니 환전·현금 거래·알선은 금지이며 적발 시 계정 이용제한과 게임머니 회수 | → 05 WPL §5, 윈조이 §8 |
| 네오위즈 | 2019년 쪽지·채팅 차단, 비정상 결제 탐지(FDS), 수사 의뢰, 환전 홍보 영상 삭제 조치를 회사가 밝힘 | → 06 피망 포커 §8 |
| 고지 | 각 게임의 스토어 설명: "게임머니는 현금이나 경품 등 재산상 가치가 있는 어떤 것으로도 교환되지 않습니다" | → 07 §0.2, 05 윈조이 §5 |

- 법 조문은 법률 해설 글에서 읽은 요지다. 조문 원문과 최신 개정 여부는 국가법령정보센터에서 확인해야 한다.
- 게임 안에서 딴 참가권으로 나가는 오프라인 대회의 상금은 별개의 구조다(주최사가 지급, 참가권은 기명·양도 불가). (→ 08 §6)
