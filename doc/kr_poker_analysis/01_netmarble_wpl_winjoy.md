## 3. 로비 화면 구조
### 3.1 와이어프레임 (ASCII, 대략적 비율 표기)
메인 로비 전체 스크린샷은 확보하지 못했다 → 레이아웃 [미확인]. 아래는 **로비 하위 화면(랭킹)** 에서 확인한 공통 프레임이다 [관찰: WEB-4].
```
+----------------------------------------+
| (G) 549man 3291  (W) 6790    <D> 0 [=] |  TOPBAR  ~4%
| [<] TITLE (i)                          |  HEADER  ~5%
|  TAB1   TAB2   TAB3                    |  TABS    ~4%  (active = blue text + underline)
| +------------------------------------+ |
| | [AVATAR] rank title   period  [BTN]| |  CARD LIST (red = tournament, blue = holdem)
| +------------------------------------+ |
| | ...                                | |
+----------------------------------------+
```
범례: `(G)` 금색 코인 재화, `(W)` 빨간 W 칩 재화, `<D>` 다이아, `[=]` 햄버거 메뉴, `[<]` 뒤로, `(i)` 도움말, `[BTN]` 참여 상태 버튼("참여안함").
### 3.2 영역별 구성요소
- **상단 재화 바**: 좌측 코인(`549만 3291`처럼 한국식 단위), 빨간 W 칩, 우측 다이아와 햄버거 [관찰: WEB-4]. W 칩은 "포커칩"으로 보이며 포커칩 재화와 관련 UI는 2026-04-22 제거됐다고 공지됨 → 현재 바 구성은 다를 수 있음 [추정: WEB-8].
- **서브 화면 헤더**: `< 제목 ⓘ` + 텍스트 탭(활성 탭 파란 글자·밑줄) + 필(pill) 칩 필터(활성 = 흰 바탕) [관찰: WEB-4, WEB-15].
- **로비 진입점(공지로만 확인)**: 하단 `[HERO]`, `토너먼트` 탭, `소셜`, `보관함`, `[WPL TV]` 버튼(신규 영상 알림 배지), 동영상 충전소(보상·잔여 횟수 로비 노출), 코인드랍 알림 [관찰: WEB-11, WEB-12]. 하단 탭바의 정확한 항목·순서 [미확인].
- **배너·이벤트**: 홈페이지는 대회(홀덤 마스터스)·시리즈 중심 [관찰: WEB-23]. 인게임 로비 배너 [미확인].

- **구성**: 원형 아바타(입체감 있게 그린 카툰풍 캐릭터, 지름 ≈ 화면 폭 13~15%) + 그 아래 반투명 검정 둥근 사각 패널에 2줄(닉네임 회색 소형 / 보유 칩 흰색 굵게) [관찰: AS-wpl-iphone-01].
- **히어로**: 아바타가 상대의 약 1.6배(폭 ≈ 22%), 패널도 큼. 닉네임 예시 "닉네임은여덟글자" → 8자 기준 폭 [관찰] / 닉네임 최대 8자 [추정].

### 4.4 카드
- **내 카드**: 2장을 겹치지 않고 나란히, 아바타 오른쪽에 크게(카드 높이 ≈ 화면 높이 10%) [관찰: AS-wpl-iphone-01]. AOF 목업에서는 한 장에 하늘색 글로우 테두리 [관찰: AS-wpl-iphone-05] — 족보/빙고 참여 카드 강조 [추정].
- **커뮤니티 카드**: 5장 한 줄, 간격 좁게, 화면 폭의 약 60%, 세로 36~43% 지점. 빈 슬롯은 얇은 외곽선 사각형 5개 [관찰: AS-wpl-iphone-01, WEB-3].
- **상대 카드**: 뒷면 2장을 기울여 겹쳐 아바타 바깥쪽 옆에 작게 표시, 쇼다운 시 앞면 2장이 아바타 자리를 덮음 [관찰: AS-wpl-iphone-01, -02].
- **덱 디자인**: 흰 바탕, 좌상단 큰 랭크+작은 수트, 우하단 큰 수트 1개(J/Q/K는 그림). **2색 덱**(♠♣ 검정, ♥♦ 빨강) [관찰]. 4색 덱 옵션 [미확인]. 뒷면은 파랑·흰색 마름모 격자+스페이드 엠블럼 [관찰]. "카드덱"이 보관함 항목·상품으로 존재 → 덱 스킨 교체 가능 [관찰: WEB-11].
- **쇼다운 강조**: 족보에 쓰인 카드는 금색 글로우, 나머지는 어둡게, 족보명은 보드 아래 큰 글씨 [관찰: WEB-3].

- **개인 베팅**: 좌석에서 테이블 중앙 쪽으로 칩 더미 아이콘+흰 금액 [관찰].
- **금액 표기**: 테이블 안은 **한국식 단위 상위 2단위**·천 단위 쉼표 없음(`15만8530`, `1만340`, `12억6500만`, `7조 2000억`, `7989억9154만`). 단위 사이 띄어쓰기는 목업마다 다름 [관찰: AS-wpl-iphone-02, -04, -05]. 잭팟·순위는 쉼표 전체 표기(`985,592,584,555`, `32/1,500`) [관찰].
