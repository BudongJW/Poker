# 국내 포커 게임 UI 비교 — 공통 구조와 차이

> 분석 기준일: 2026-11-13. 이 문서는 회사별 문서 세 편을 가로로 묶은 요약이다.
> 개별 사실의 근거(스크린샷 ID, URL)와 [관찰]/[추정] 구분은 각 문서에 있다. 여기서는 `→ 01 §4.6`처럼 해당 절만 가리킨다.
> (01 = 넷마블 WPL·윈조이, 02 = 네오위즈 피망, 03 = NHN 한게임)

## 1. 핵심 결론

1. **화면 문법은 회사가 아니라 계열로 갈린다.** 세 회사 모두 ① 가로 화면의 웹보드형 종합 포커와 ② 세로 화면의 국제 룰 홀덤 전용 앱을 따로 운영한다. 같은 회사의 두 앱보다 다른 회사의 같은 계열 앱이 서로 더 닮았다.

   | | 웹보드형(가로) | 홀덤 전용(세로) |
   |---|---|---|
   | 넷마블(잼팟) | 윈조이 포커 | WPL |
   | 네오위즈 | 피망 포커 | 피망 쇼다운 홀덤 |
   | NHN | 한게임 포커, 한게임포커 클래식(+PC) | 한게임 로얄홀덤 |

   한게임 홀덤은 두 계열의 중간이다. 가로 화면에 5인 타원 테이블을 쓰고, 베팅은 웹보드식 고정 버튼과 슬라이더식을 모두 지원한다. (→ 03 §4.B)

2. **웹보드형의 공통 골격**: 좌 2·우 2·하단 1의 5인 배치, 플레이어별 카드 트레이, 중앙의 `Total/Call`(또는 `POT/CALL`) 2행 박스, 화면 맨 아래를 가로지르는 **6칸 베팅 바**, 내 패 옆의 족보 보조 패널.

3. **홀덤 전용의 공통 골격**: 세로로 긴 타원(또는 물방울) 테이블, 9인은 상 2·좌 3·우 3·하 1, 내 자리는 하단 중앙, 맨 아래 **3버튼 액션바**, 좌상단 **테이블 탭**(탭에 그 테이블의 내 홀카드를 그려 넣는다)으로 멀티테이블.

4. **홀덤 전용 3종의 액션 색 관례가 일치한다.** 버튼 바탕은 어둡게 두고 글자색으로 구분한다: 폴드 = 흰색/회색, 콜 = 파랑·시안, 베팅/레이즈 = 금색·노랑, 체크 = 녹색.

5. **금액은 전부 한글 단위(만·억·조)로 쓴다.** 상위 두 단위까지만 보여 주는 것이 기본이고, 잭팟 카운터만 쉼표 구분 전체 숫자를 쓴다. 띄어쓰기·0 채움·소수점 같은 세부 규칙은 앱마다 다르다.

6. **펠트 색이 종목·모드의 식별자다.** 다만 색 배정은 서비스마다 달라서, 세 회사가 일치하는 것은 "7포커 = 남색" 정도다.

7. **초보자 보조가 두껍다.** 현재 족보명 상시 표시, 족보 목록·승률 패널, 시작 핸드 별점, 누르기 전에 금액을 알려 주는 버튼 탭이 거의 모든 앱에 있다.

## 3. 계열 A — 웹보드형 테이블의 공통 골격

```
+----------------------------------------------------------------------------+
| GAME [JACKPOT]              [DECK]              [LOG][SET][MOVE][EXIT]     |  0-10%
| (AV) [ card tray  ] act                          act [ card tray  ] (AV)   | 12-33%
| name / money        bet                          bet        name / money   |
|                         [ chips ]                                          |
| (AV) [ card tray  ] act  +--------------+        act [ card tray  ] (AV)   | 36-60%
| name / money             | Total      n |                   name / money   |
|                   (BOSS) | Call       n |                                  |
|                          +--------------+                                  |
|           (ME) [  my cards (large)   ]   [ RANKS / WIN% / RESULT ]         | 60-86%
|          name / money      hand-name                                       |
| [ b1 ][ b2 ][ b3 ][ b4 ][ b5 ][ b6 ]                                       | 86-100%
+----------------------------------------------------------------------------+
```
범례: AV=아바타, card tray=플레이어별 카드 영역, act=직전 액션 표시, bet=이번 라운드 베팅액, BOSS=보스(선) 표식, RANKS=족보 목록, b1~b6=베팅 버튼.

| 구역 | 공통점 | 서비스별 차이 |
|---|---|---|
| 상단 바 | 왼쪽에 종목명·잭팟, 오른쪽에 방이동·나가기 | 피망은 미션(과녁)·정보 버튼, 한게임은 기록·설정, 윈조이는 미션 보상 알약 |
| 좌석 | 좌 2·우 2, 아바타는 화면 바깥쪽 | 직전 액션 표시가 원형 배지(피망·윈조이·클래식) 또는 글자+금액(한게임 포커) |
| 중앙 | 칩 더미 + 2행 금액 박스 | 라벨이 `POT/CALL`(피망), `Total/Call`(한게임·윈조이). 한게임은 위에 `시드`/`단위`를 덧붙임 |
| 내 패 | 하단 중앙, 가장 큰 카드, 바로 아래 족보명 | 히든 카드 표시법이 다름(피망은 카드 아랫부분 격자, 한게임은 손가락 아이콘으로 쪼기) |
| 보조 패널 | 내 패 오른쪽. 진행 중엔 족보, 종료 후엔 결과표 | 피망만 족보별 승률(%)을 함께 표시. PC 한게임은 같은 자리에 채팅 탭 |
| 베팅 바 | 화면 맨 아래 전폭 6등분, 위치 고정, 못 누르는 버튼은 흐리게 | 라벨 순서와 색 규칙이 서비스마다 다름(아래 표) |

### 6칸 베팅 바의 라벨 순서
| 서비스 | 1 | 2 | 3 | 4 | 5 | 6 | 색 규칙 |
|---|---|---|---|---|---|---|---|
| 피망 포커 | 다이 | 삥 | 따당 | 체크 | 쿼터 | 하프 | 버튼 왼쪽 원형 램프 색 |
| 윈조이 포커 | 체크 | 삥 | 하프 | 풀 | 콜 | 다이 | 버튼 왼쪽 원형 표시등 |
| 한게임 포커 | 다이 | 삥 | 콜 | 쿼터 | 하프 | 맥스 | 글자색(버튼마다 다른 색) |
| 한게임포커 클래식 | (잘림) | 따당 | 콜 | 쿼터 | 하프 | 풀 | 글자색 |

- 칸 수는 같지만 **`다이`의 위치가 다르다.** 피망·한게임은 맨 왼쪽, 윈조이는 맨 오른쪽이다.
- 라벨은 상황에 따라 같은 칸에서 바뀐다(삥↔따당, 체크↔콜, 하프↔올인). 칸의 위치는 고정이고 라벨이 변한다. (→ 02 §A-4.7, 03 §4.C)
- 누를 수 있는 금액 버튼 위에 결과 금액을 띄우는 탭/툴팁은 세 서비스 공통이다.
- PC는 배치가 다르다. 한게임 PC는 2열×4행 그리드에 숫자 단축키를 상시 표기하고(→ 03 §4.D), 윈조이 PC 가이드는 2×3 그리드와 버튼 타입 3종을 보여 준다(→ 01 §W.4, 구형 화면일 수 있음).

## 4. 계열 B — 홀덤 전용 테이블의 공통 골격

```
+--------------------------------------+
| [T1][T2][+]                 [SHOP](=)|   2-7%   table tabs / menu
| [RANK n/N]            [LEVEL TIMER]  |   8-13%  tournament only
|          (S)        (S)              |
|   (S)                      (S)       |
|             blind / ante text        |
|   (S)          [ POT ]     (S)       |
|        [C1][C2][C3][C4][C5]          |  36-49%  board
|   (S)                      (S)       |
|            (D)   my bet              |
|  [ic]     (ME) [H1][H2]              |  55-75%  hero
|  [ic]     name / stack   hand-name   |
| [ FOLD ]  [ CHECK/CALL ]  [ BET ]    |  88-97%  action bar
+--------------------------------------+
```
범례: T1·T2=참여 중인 테이블 탭, (=)=메뉴, S=상대 좌석, C1~C5=공용 카드, H1·H2=내 카드, ic=이모티콘·상점 등 보조 아이콘.

| 요소 | WPL (→ 01 §4) | 피망 쇼다운 홀덤 (→ 02 §B-4) | 한게임 로얄홀덤 (→ 03 §4.A) |
|---|---|---|---|
| 테이블 모양 | 세로 타원(레이스트랙) | 위가 좁은 물방울형, 원근감 | 세로 타원 |
| 테이블 탭 | `대기` + 홀카드 탭 + `+` | 홀카드 썸네일 + 족보명 + `+` | 홀카드 썸네일 + 상태(폴드/대기) + `+` |
| 블라인드 표기 | 펠트 위 한글 `블라인드 : 5000 / 1만(1000)` | 펠트 위 영문 `Ante 100 / SB : 100 / BB : 200` | 펠트 위 이탤릭 `5천만 / 1억`, 토너는 `Ante 20 / 100 / 200` |
| 팟 | `Pot` 텍스트 + 칩 알약 2단, 사이드팟 `S1` 행 | `POT` 태그 + 칩 알약, 사이드팟 번호 알약 | 보드 바로 위 칩 알약 1단 |
| 공용 카드 위치(세로) | 약 36~43% | 약 41~49% | 약 49% |
| 내 카드 | 아바타 오른쪽에 나란히 | 아바타 위에 벌려 겹침 + 별점 | 아바타 오른쪽에 나란히 |
| 상대 액션 표시 | 아바타 위 알약 배지(폴드·체크·올인!) | 아바타 옆 색 말풍선(콜·레이즈·체크·폴드·올인) | 아바타 위 알약 말풍선(레이즈·콜·폴드) |
| 턴 타이머 | 좌석 쪽 표현 미확인 | 아바타 둘레 원형 링 | 아바타 둘레 노란 원호 |
| 액션바 | 3버튼, 올인·AOF는 2버튼 | 3버튼, 올인 직면 시 2버튼, 종료 후 `공개` 3버튼 | 모바일 미확인, PC는 3버튼 + 단축키 |
| 예약(사전 선택) | 미확인 | 버튼 왼쪽 램프 막대로 겸용 | 구버전 `CHK/FOLD·CHECK·CALL ANY`, 현행 미확인 |
| 금액 선택 | 오른쪽 세로 슬라이더 + 원형 프리셋 | 미확인 | PC: 가로 슬라이더 + BB 프리셋 + 입력칸 |
| 토너먼트 표시 | `현재순위 32/1,500` 배지, 다음 블라인드 2행 | `현재 순위 39 / 60`, `Next LV.` 타이머, `리바이` | `현재 순위 17 / 1240`, 휴식 시간 표시 |
| 포지션 마커 | 흰 `D`, 파란 `SB`/`BB` | 흰 `D`, 파란 `SB`, 붉은 `BB`, `PB` | 흰 `D`, 분홍 `SB`, 파란 `BB` |
| 하단 탭(로비) | 미확인 | 로비·상점·보관함·미션·랭킹 | 로비·상점·보관함·미션·랭킹 |

- 쇼다운 홀덤과 로얄홀덤은 로비 하단 탭 구성까지 같다. 로비 본문도 "배너 캐러셀 + 빠른 참여 카드" 구조로 닮았다. (→ 02 §B-3, 03 §3.A)
- 세 앱 모두 PC 버전이 있다(쇼다운 홀덤은 2026-03 출시, 화면 자료는 구하지 못했다). 화면을 확인한 WPL과 로얄홀덤의 PC 테이블 창에서는 액션 영역이 **오른쪽 아래**로 옮겨 간다. 로얄홀덤은 버튼마다 단축키(F·C·R, 숫자 1~4)가 표기되고, WPL은 키보드 아이콘만 확인돼 단축키 지원은 추정이다. (→ 01 §4.6, 03 §4.A)

## 5. 구성요소별 패턴

### 5.1 카드
- 기본은 모두 2색 덱(♠♣ 검정, ♥♦ 빨강)이다.
- 덱을 바꿀 수 있는 흔적: 피망 포커의 4색 덱 실캡처(→ 02 §A-4.5), 로얄홀덤의 무늬별 색 채움 덱(→ 03 §4.A), WPL의 카드덱 상품(→ 01 §4.4).
- 웹보드형은 카드를 좁게 겹쳐 **왼쪽 인덱스만** 보이게 하고 마지막 카드만 전체를 보여 준다. 홀덤 전용은 겹치지 않고 숫자를 크게 쓴다(쇼다운 홀덤은 작은 인덱스 + 큰 숫자 이중 표기, 로얄홀덤은 그림 카드에도 인물 그림이 없다).
- 승리 족보에 쓰인 카드는 금색(또는 청록) 테두리로 밝히고 나머지는 회색으로 어둡게 하는 처리는 전 앱 공통이다.

### 5.2 금액 표기
| 규칙 | 해당 앱 |
|---|---|
| 한글 단위 상위 2단위, 붙여 씀 (`53조363억`) | 피망 포커, WPL(일부) |
| 한글 단위 상위 2단위, 단위 뒤 공백 (`4만 2200`) | 쇼다운 홀덤, 한게임 계열, WPL(일부) |
| 4자리 0 채움 (`22억 0000만`) | 한게임 포커 |
| 최상위 단위 + 소수 (`4.966조`) | 윈조이 포커 |
| 1 단위까지 전부 (`33억 8165만 9375골드`) | 한게임포커 클래식 |
| 쉼표 정수 (`3,800`, `+57,300`) | 로얄홀덤 토너먼트, 각 앱의 잭팟 카운터 |
| BB 단위 (`49.7BB`) | 로얄홀덤, WPL(옵션·코인러시) |

- 한 앱 안에서도 자리(보유액 / 팟 / 버튼 탭 / 잭팟)에 따라 규칙이 달라진다.
- 화폐 단위 글자(`골드`, `칩`)는 팟·버튼 쪽에만 붙고 보유액에는 생략되는 경우가 많다.

| 내 패 옆 현재 족보명 | ○ | ○ | ○ | ○ | ○ | ○ | 쇼다운 때 | ○ |
| 족보 목록 패널 | – | ○ | ○ | – | ○ | ○ | – | ○ |

### 5.4 승패·특수 연출
- 큰 족보는 화면 중앙에 **영문 대문자 배너**로 띄운다(`STRAIGHT FLUSH`, `FOUR OF A KIND`, `ROYAL STRAIGHT FLUSH`). 한글 족보명은 내 패 옆에 작게 병기한다. 전 앱 공통.
- 승자 표시는 금색 `WINNER`(한게임 포커는 `WIN`) + 획득액.
- 올인은 붉은 배지에 불꽃·말풍선 효과.
- 웹보드형은 결과표(닉네임·족보·손익), 잭팟 간판, 땡값·딜러비 표기가 추가된다.
- 피망 포커·한게임포커 클래식·한게임 홀덤은 결과 단계에서 **하단 베팅 바가 감정표현(텍스티콘) 버튼 줄로 바뀐다.**

### 5.5 로비
| 계열 | 흐름 | 화면 구성 |
|---|---|---|
| 웹보드형 모바일 | 종목 탭 → 채널(판돈 등급) 카드 → 자동 배정 | 상단 프로필·재화, 사다리꼴 종목 탭, 채널 카드, 하단 아이콘 메뉴 |
| 웹보드형 PC | 종목 탭 → 채널 → 대기실(방 목록) → `바로입장`/`방만들기` | 방 카드 목록 + 우측 내 정보 사이드바 (→ 03 §3.B, 01 §W.4) |
| 홀덤 전용 | 모드 아이콘·빠른 참여 카드 → 목록 → 바이인 → 테이블 | 배너 캐러셀, 모드 아이콘 격자, 빠른 참여 카드, 하단 탭 5개 |

- 채널 이름은 실력 등급 은유를 쓴다: 피망 `메이저·프로·마스터`, 한게임 `시니어·세미프로·프로·챔피언`, 쇼다운 `루키·챌린저·세미 프로·프로·마스터·챔피언 아레나`, WPL 코인러시 `피쉬·중수·프로·마스터`.
- 테이블에서 나가지 않고 다른 방으로 옮기는 `방이동` 버튼은 웹보드형 공통이다.

## 7. 국내 서비스에서만 두드러지는 요소

- **인증 배지의 전면 배치**: RNG 인증(Gaming Labs Certified)과 이용자보호인증(GUCC) 마크가 스토어 스크린샷 한 장을 통째로 차지하고, 쇼다운 홀덤은 설정 화면에도 넣는다. (→ 02 §B-1, 각 문서의 근거 자료 표)
- **웹보드 규제가 만든 UI**: 임의 상대와 붙는 `바로입장`·자동 배정이 기본 동선이고, 지인과 하는 방은 `친구대전`·`친구 경기장`처럼 별도 채널로 분리된다. 윈조이 PC 가이드에는 한도 안내, 시간 알리미, 짜고치기 신고 버튼이 화면 구성요소로 명시돼 있고, 한게임 PC는 친구 경기장의 베팅 한도를 따로 둔다. (→ 01 §W.4, 03 §4.D) 규제와의 인과는 추정이다.
- **홀덤의 현지화**: 피망 포커·한게임 포커·윈조이 포커는 홀덤에도 삥·쿼터·하프 버튼을 쓴다. 한게임은 5인 "K-홀덤"에 금액이 적힌 버튼(`2억·5억·10억`)을 쓰고, 블라인드 대신 `시드`로 판 크기를 표기한다. (→ 02 §A-4.7, 03 §4.B)
- **웹보드 고유 규칙의 시각화**: 땡값 지불 라벨, 딜러비, 보스(선) 칩, 로우바둑이의 아침·점심·저녁 탭과 교환 장수 표시.
- **사교 장치**: 플레이어마다 붙는 선물(컵) 아이콘, 텍스티콘, 클럽·길드 메뉴.

## 8. 고정 요소와 가변 요소

화면을 설계하거나 해석할 때 무엇이 안정적이고 무엇이 흔들리는지 정리한다.

|---|---|
| 내 좌석은 하단 중앙 | 8개 앱 전부 |
| 액션 버튼은 화면 맨 아래 줄(모바일), 칸의 위치 고정 | 8개 앱 전부. PC는 오른쪽 아래 |
| 공용 카드는 테이블 중앙 한 줄, 팟은 그 위 또는 아래에 인접 | 홀덤 화면 전부 |
| 우상단에 나가기·방이동·메뉴 | 웹보드형 전부 |

|---|---|
