## 0. 개요

네오위즈는 성격이 전혀 다른 두 개의 포커 앱을 운영한다. 하나는 전통 웹보드 계열(가로 화면, 삥·따당·쿼터·하프 베팅)인 **피망 포커**, 다른 하나는 국제 룰 홀덤 전용(세로 화면, 폴드·콜·레이즈)인 **피망 쇼다운 홀덤**이다.

## A-2. 정보 구조와 화면 흐름

```
스플래시 ─▶ 로비 ─┬─ 종목 탭(7포커 / 로우바둑이 / 하이로우 / [홀덤])
                  │     └─ 채널 카드(메이저·프로·마스터… / 친구대전) ─▶ 테이블(자동 배정)
                  ├─ 하단 메뉴: 상점 · 내가방 · 미션 · 이벤트
                  ├─ 상단: 프로필 · 금고 · 설정
                  └─ 부가: 클럽 · 업적 · 랭킹 페스타 · 럭키박스 · 무료충전소
테이블 ─▶ (핸드 반복) ─▶ [방이동] 다른 방으로 / [나가기] 로비로
```

- 채널 카드를 누르면 방 목록 없이 바로 테이블로 들어가는 구조로 보인다. 테이블 우상단에 `방이동` 버튼이 따로 있다는 점이 근거다. [추정: `WEB-1`, `AS-…-iphone-02`]
- 홀덤 탭이 로비에 어떻게 배치되는지는 구버전 캡처에 없다. [미확인]

### 영역별 구성요소
- **상단 바**: 좌측에 원형 아바타·레벨·닉네임·VIP 배지, 우측에 골드 잔액(금색 숫자)과 `금고` 버튼, 루비 수량, 톱니 설정 버튼. [관찰: `WEB-1`] 클럽·업적 화면도 같은 구조의 재화 바(골드+금고 / 루비 / 티켓)와 우측 `X` 닫기 버튼을 쓴다. [관찰: `AS-…-iphone-06`, `-07`]
- **종목 탭**: 사다리꼴 탭. 선택된 탭은 밝은 파랑, 비선택 탭은 종목 고유색(로우바둑이=보라, 하이로우=녹색)으로 어둡게 깔린다. 이 탭 색이 곧 테이블 펠트 색과 대응한다. [관찰: `WEB-1`]
- **채널 카드**: 파란 글로시 카드에 채널명(메이저/프로/마스터), 접속 인원, 기준 머니 알약. 입장 불가 채널은 채도가 낮게 표시된다. `친구대전` 카드는 금속 질감의 "VS" 로고만 둔다. [관찰: `WEB-1`]
- **이벤트 줄**: 좌측에 큰 일러스트형 프로모션 3개, 우측에 작은 선형 아이콘 5개(피망섯다·무료복권·동영상·무료충전소·패밀리게임). [관찰: `WEB-1`]
- **하단 메뉴**: 상점 · 내가방 · 미션 · 이벤트. 빨간 원형 배지로 개수/신규(N)를 표시. [관찰: `WEB-1`]
- 현재 버전(v138)의 로비 캡처는 확보하지 못했다. 클럽·업적·랭킹 페스타·홀덤이 추가된 뒤의 배치는 [미확인].

## A-4. 게임 테이블 화면 구조

### A-4.1 공통 프레임 (모든 종목)
```
+----------------------------------------------------------------------------+
| GAME-NAME [JACKPOT TICKER]      [DECK SHOE]        (M)(i) [MOVE] [LEAVE]    |  0-8%
|                                                                            |
|                         << table area (per game) >>                        |  8-86%
|                                                                            |
| (EMO)                                                              (BTN)   |  ~79%
+----------------------------------------------------------------------------+
| [DIE] [BBING] [DDADANG] [CHECK/CALL] [QUARTER] [HALF] ...  6 slots          |  88-100%
+----------------------------------------------------------------------------+
```
범례: GAME-NAME=좌상단 회색 종목명, JACKPOT TICKER=점선 전구 테두리 전광판, DECK SHOE=상단 중앙 카드 슈(홀덤은 대신 블라인드 명판), M=과녁 모양 미션 버튼, i=정보, MOVE=방이동, LEAVE=나가기, EMO=이모티콘 말풍선 버튼.

- 좌상단 종목명은 크고 흐린 회색 글자로 배경에 묻히듯 놓인다. 바로 옆에 잭팟 전광판이 있어 누적 금액(`350,436,581,941,753`처럼 쉼표 구분 숫자)이나 당첨 소식("7포커에서 "이사"님…")이 흐른다. [관찰: `AS-…-ipad-03`, `-04`]
- 우상단 버튼 4개는 모든 종목에서 위치·모양이 같다: 과녁 아이콘, `i`, `방이동`, `나가기`. [관찰]
- 하단 바는 화면 높이의 약 9~12%를 차지하는 6칸 버튼 줄이다. 상태에 따라 베팅 바 → 하이로우 선언 버튼 → 감정표현 바로 **같은 자리에서 교체**된다. [관찰: `GP-pmang_poker-02`, `-03`, `AS-…-ipad-02`]

```
+----------------------------------------------------------------------------+

|              (S2)                                   (S3)                    |  y~16%

|                   +----+----+----+----+----+                                |

|  [name/stack]            [stack] hand-name               [name/stack]       |
| (EMO)                                                              (BTN)    |
+----------------------------------------------------------------------------+
| [o DIE] [o BBING] [o CHECK] [o QUARTER] [o HALF] [ ...]                      |

```
범례: S0~S5=상대 좌석(좌하→좌중→좌상→우상→우중→우하), ME=내 좌석(하단 중앙), C1~C5=공용 카드, H1·H2=내 카드, D=딜러 버튼, o=버튼 왼쪽의 색 램프.

- **좌석**: 상대 6석 + 나 1석, 총 7석이 보인다(좌상·우상·좌중·우중·좌하·우하·하단 중앙). 최대 인원이 7인지 그 이상인지는 [미확인]. 내 자리는 항상 하단 중앙. [관찰: `AS-…-iphone-02`, `GP-pmang_poker-02`]
- **테이블**: 진한 빨강 펠트(≈`#76090F`)의 가로 타원, 검은 가죽 레일, 배경은 거의 검정(≈`#0A0806`)의 석재 질감. [관찰]
- **블라인드 명판**: 상단 중앙의 어두운 붉은 사다리꼴에 `블라인드  1조/2조 (1조)`. 괄호 값의 의미(앤티 또는 최소 바이인)는 [미확인].
- **POT**: 공용 카드 위쪽에 칩 아이콘 + 금색 숫자의 어두운 알약(≈`#2A0001`). [관찰]
- **공용 카드**: 화면 폭의 약 29~71%, 높이 약 32~51% 구간에 5장을 겹침 없이 나열. 승리 족보에 쓰인 카드는 금색 광채, 나머지는 회색으로 어둡게 처리한다. [관찰: `AS-…-iphone-02`]
- **족보 표시**: 쇼다운 때 공용 카드 아래에 파란 이탤릭 영문("STRAIGHT FLUSH"), 내 카드 옆에는 한글 족보명("8 스트레이트 플러시")을 금색 작은 글씨로 병기. [관찰]
- **내 카드**: 내 아바타 오른쪽에 크게 2장. 차례가 오면 아바타 둘레에 주황 광채 링. [관찰: `GP-pmang_poker-02`]

### A-4.8 족보·승률 패널, 결과 연출
- **족보 | 내승률 패널**: 내 카드 오른쪽의 어두운 표. 족보 순위 번호 + 족보명 + 확률(%)을 5줄 보여 주고, 현재 완성된 족보를 녹색으로 강조한다(예: `11 원페어 14%`, 로우바둑이 `13 베이스 89%`). 하이로우는 하이(파란 ▲)와 로우(빨간 ▼) 두 구획으로 나뉜다. [관찰: `WEB-1`, `AS-…-ipad-03`, `-05`]
- 내 카드 아래 알약에 현재 족보명(`2 원페어`, `A 3 8 베이스`, `7 원페어 / 10 탑`). [관찰]
- **로우바둑이 전용**: 중앙에 `아침 · 점심 · 저녁` 탭(현재 라운드 빨간 밑줄), 각 플레이어 트레이 옆에 라운드별 교체 장수 3개가 세로로 쌓인다(`3 / 1 / 1`). [관찰: `AS-…-ipad-03`]
- **하이로우 전용**: 선언 단계에 하단 바가 큰 버튼 3개(`↑ 하이` 파랑, `↕ 스윙` 녹색, `↓ 로우` 빨강)로 바뀐다. 플레이어 트레이 옆에 큰 `?` 또는 `!` 기호가 뜬다(미선언/선언 완료 구분으로 보임). [관찰: `AS-…-ipad-05`, `WEB-1` / 의미는 추정]
- **승리 연출**: 내 카드 위에 금색 `WINNER` 배너와 획득액, 화면 중앙에 큰 금색 `+72조6718억 골드`. [관찰]
- **게임결과 표**: 우하단의 파란 테두리 패널. 행마다 닉네임 · 족보 · 손익, 승자 행에 `WIN` 태그. [관찰: `AS-…-ipad-04`]
- **땡값**: 패자의 트레이에 붉은 줄무늬 라벨 `땡값지불 -11조 5000억 골드`. [관찰]
- **잭팟**: 전구가 달린 네온 간판(`Jackpot +1조7002억골드 ROYAL STRAIGHT FLUSH`)이 중앙 상단을 덮고, 승자 아바타에 불꽃 테두리가 붙는다. [관찰]
- 결과 단계에서 하단 바는 `감사 · 미안 · 축하 · 기쁨 · 슬픔 · 화남` 감정표현 알약 6개로 교체된다. [관찰: `AS-…-ipad-02`, `-04`]

### B-4.2 좌석 배치
- 9인 테이블: 위 2석, 왼쪽 3석, 오른쪽 3석, 아래 중앙에 나. 테이블이 위는 좁고 아래는 넓은 **물방울(달걀) 모양**이라 원근감이 생긴다. [관찰: `AS-…-iphone-04`, `-05`]

### B-4.3 플레이어 패널
- **3D 렌더링 아바타 흉상**(애니메이션 영화풍 인물·용 등). 테두리 없이 테이블 가장자리에 걸쳐 놓는다. 표정이 상황에 따라 바뀐다(올인 시 놀란/신난 표정). [관찰]
- 아바타 아래 2줄: 닉네임(회색) + 스택(흰색). 아바타 옆에 작은 카드 뒷면 2장(핸드 보유 표시). [관찰]
- **액션 말풍선**: 아바타 옆에 색으로 구분된 말풍선 — `콜` 파랑, `레이즈` 주황, `체크` 녹색, `베팅` 베이지, `폴드` 회색, `올인` 불꽃 붙은 빨강. [관찰: `AS-…-iphone-04`, `-05`]
- **턴 타이머**: 아바타 둘레의 원형 링(파랑/보라)이 줄어들고 끝점에 불꽃 효과. [관찰: `AS-…-iphone-05`, `WEB-3`]
- **자리 비움**: 아바타가 회색조로 바뀌고 커피잔 아이콘 원이 붙는다. [관찰 / 의미는 추정]
- **승자**: 아바타에 광채 + `+2만 4000` + 금색 `WINNER` 배지. [관찰]

### B-4.4 카드
- 2색 덱. **왼쪽 위 작은 인덱스(숫자+무늬) + 아래쪽 큰 숫자**의 이중 표기라 작은 화면에서도 숫자가 잘 읽힌다. 그림 카드도 일러스트 없이 글자(J·Q·K)만 크게 쓴다. [관찰]
- 공용 카드: 화면 폭 대부분을 쓰는 5칸. 아직 열리지 않은 칸은 회색 뒷면으로 자리만 표시(턴까지 열린 상태에서 다섯째 칸). [관찰: `AS-…-iphone-05`]
- 내 카드: 2장을 살짝 벌려 겹치고 아바타 위에 걸친다. 카드 왼쪽에 **별 1~5개의 포켓 등급**(시작 핸드 강도)이 세로로 표시된다. [관찰: `WEB-2`, `WEB-3`]
- 족보 강조: 승리 족보 카드에 금색 테두리 광채, 해당 없는 카드는 어둡게. [관찰: `AS-…-iphone-03`]
- 3D 카드 쪼기: 내 카드를 3D 공간에서 직접 들춰 보는 전체 화면 연출. [관찰: `WEB-2`, 스토어 설명]

### B-4.5 팟·베팅 표시
- 펠트 위에 인쇄된 듯한 글씨로 `Ante 100` / `SB : 100 / BB : 200`(이탤릭, 반투명). [관찰]

- 각 플레이어의 베팅은 좌석 앞 펠트 위 칩 더미 + 노란 숫자. [관찰]

### 신뢰도·한계
- 스토어 스크린샷은 홍보용으로 연출된 화면이다. 하단 카피가 액션 영역을 가리는 경우가 많아, 가려진 부분은 구글 플레이용 합성 이미지와 실캡처로 보완했다.
- 피망 포커 로비는 2022년 캡처만 확보했다. 홀덤·클럽·업적이 추가된 현재 로비 배치는 확인하지 못했다.
- 위치 비율과 HEX 색은 압축된 스크린샷에서 읽은 근사값이다. 실제 클라이언트와 수 % / 수 단계 차이가 날 수 있다.
- 공식 사이트(pmang.com)는 자동 접근을 차단하므로 조사하지 않았다. 피망 포커 PC 화면은 "모바일과 동일한 환경"이라는 2019년 발표(`WEB-6`)에 기대어 가로형 모바일 화면과 같은 구조로 간주했을 뿐, 직접 확인하지 못했다.
- 쇼다운 홀덤의 베팅 금액 선택 UI, 핸드 히스토리, 채팅은 자료가 없어 다루지 못했다.
